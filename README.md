# Proyectos de Kodland Python Pro

- **rutas_flask**: inicio, datos aleatorios y página secreta con lanzamiento de moneda.
- **calculadora**: plantilla del curso terminada, tarjetas ecológicas y formulario con guardado en form.txt.
- **generador_memes**: textos, colores, posiciones y tres plantillas originales.
- **bots**: comandos de memes, rareza, patos y reciclaje; requiere DISCORD_TOKEN para conexión a Discord.
- **diario**: SQLite, usuarios, contraseñas con hash y entradas privadas.
- **portafolio**: cuatro competencias dinámicas, avatar y comentarios guardados.
- **tecnologia**: página HTML/CSS con Inter y paleta Kodland.
- **resumidor**: PNL con NLTK, entrada por archivo, longitud configurable y recopilación de diez noticias.
- **Analisis_Kodland.ipynb**: datos originales y cinco respuestas calculadas.
- **Resumidor_Noticias_Kodland.ipynb**: pipeline de NLTK, pruebas y salidas reales de diez noticias.

## Validación y límites
Las aplicaciones Flask se probaron con sus clientes de pruebas: navegación, formularios y persistencia. El diario incluye pruebas de aislamiento entre usuarios. Ambos cuadernos se ejecutaron con Python localmente, no en un servidor Colab. No se probó el bot conectado a Discord y no se entrenaron modelos de visión artificial. No se ha desplegado en PythonAnywhere.

Las plantillas originales de calculadora, memes y portafolio proceden de GitKodland y están citadas en cada carpeta. Las imágenes remotas del portafolio proceden de esa misma plantilla.
