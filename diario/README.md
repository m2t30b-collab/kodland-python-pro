# Diario del programador
SQLite, modelos User y Card, altas de usuarios, contraseñas con hash, sesión y entradas privadas por usuario.
Inspirado en la actividad https://github.com/GitKodland/diary-en, con plantillas propias en español.

Instalar requisitos y ejecutar python main.py. Configura SECRET_KEY persistente y DIARY_DATABASE_URI en el despliegue. No se ha desplegado en PythonAnywhere.

Pruebas: registro, acceso correcto e incorrecto, crear y recuperar entradas, aislamiento entre usuarios, rechazo de entradas vacías.
