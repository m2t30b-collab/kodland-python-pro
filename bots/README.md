# Bot educativo
Público objetivo: adolescentes que quieren reducir residuos y aprender programación.
Comandos: $mem, $animales, $duck, $reciclar papel, $reto y $help.
Memes agrupados por tema y rareza ponderada (peso 5 normal, 1 raro).

Instala requirements.txt. Crea una aplicación en Discord, activa Message Content Intent y configura DISCORD_TOKEN fuera del código. Ejecuta python bot.py.

Validación realizada: selección de archivos y temas, rareza, consejos y errores de entrada. No se ha conectado a un servidor de Discord: falta el token autorizado.
