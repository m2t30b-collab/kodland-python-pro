# Tecnología con equilibrio

Página en HTML y CSS. Usa Inter y la paleta solicitada: #5988FF, #FD98FB, #D6FF6B y #FFFFFF. Incluye bordes, tamaño y color de fuentes, color de subrayado, diseño adaptable y una animación al pasar el cursor sobre el encabezado. La fuente se carga desde Google Fonts y dispone de alternativas locales.

Abrir index.html en un navegador. Pendiente: añadir y comprobar el widget meteorológico de la actividad siguiente.
