# Portafolio educativo
Adaptado de https://github.com/GitKodland/portfolio-esp
Cuatro competencias con selección dinámica, avatar original, paleta nueva, enlaces a proyectos y comentarios guardados en feedback.jsonl.
Los iconos de la plantilla se referencian desde su repositorio original. No se envían mensajes ni correos a terceros.
Público objetivo propuesto: tutores y personas interesadas en revisar proyectos educativos en español.
Ejecutar: pip install -r requirements.txt y python main.py
